# 🔐 Программа: Шифратор/Дешифратор с выбором алгоритма

## 📝 Описание программы

Программа предоставляет простой интерфейс для шифрования и дешифрования текста с использованием двух алгоритмов: шифра Цезаря и XOR-шифрования. 

Пользователь взаимодействует с программой через консоль. Сначала он выбирает алгоритм (1 - Цезарь, 2 - XOR), затем действие (1 - шифрование, 2 - дешифрование). После этого вводит текст и ключ (для Цезаря - число сдвига, для XOR - числовой ключ). Программа выводит результат преобразования.

Программа работает в цикле, позволяя пользователю выполнять несколько операций без перезапуска. Для выхода нужно выбрать соответствующий пункт меню. Все операции выполняются в оперативной памяти, без сохранения в файлы.

## 🔍 Описание алгоритмов

### 1. Шифр Цезаря
Принцип работы: каждый символ в тексте заменяется на символ, находящийся на фиксированное число позиций (ключ) дальше в алфавите. При дешифровании выполняется обратный сдвиг. 

Особенности:

- Работает только с буквами (A-Z, a-z)
- Сохраняет регистр символов
- Не изменяет цифры и спецсимволы

[Подробнее о шифре Цезаря](https://ru.wikipedia.org/wiki/Шифр_Цезаря)

### 2. XOR-шифрование
Принцип работы: выполняется побитовая операция XOR между кодом каждого символа и числовым ключом. Интересное свойство: повторное применение XOR с тем же ключом возвращает исходный текст.

Особенности:

- Работает со всеми символами
- Чувствителен к значению ключа
- Один и тот же алгоритм используется для шифрования и дешифрования

[Подробнее о XOR-шифровании](https://ru.wikipedia.org/wiki/XOR-шифрование)


# 🎮 Проект: Игра "Виселица" 

## 📝 Описание программы

Игра "Виселица" - это классическая словоугадывающая игра, где игрок должен по буквам угадать загаданное слово за ограниченное количество попыток.

### Основные особенности:

**Выбор сложности**: перед началом игры можно выбрать уровень сложности (лёгкий - 8 попыток, средний - 7, сложный - 6)


**Механика**:

  - Программа случайно выбирает слово из предопределённого списка
  - Отображает текущее состояние слова (например, "_ _ _ _" для "кот")
  - Игрок вводит по одной букве за ход
  - При правильной букве она открывается во всех позициях
  - При ошибке уменьшается количество оставшихся попыток

**Завершение**:

  - Победа - если слово угадано полностью
  - Поражение - если закончились попытки

### Дополнительные функции:

- Проверка ввода (только русские буквы, не более одного символа)
- Защита от повторного ввода одной и той же буквы
- Возможность сыграть несколько игр подряд
- Простое меню для выбора сложности

### 3. Алгоритм работы

-Выбор сложности

-Случайный выбор слова

-Основной игровой цикл:

 - Пока есть попытки и слово не угадано:
   - Отображается текущее состояние
   - Принимается ввод буквы
   - Проверяется наличие буквы в слове
   - Обновляется состояние игры
 
-Вывод результата (победа/поражение)

-Предложение сыграть ещё раз

[Подробнее об игре Виселица](https://ru.wikipedia.org/wiki/Виселица_(игра))

### 4. Возможности для расширения

- Добавление системы очков
- Ведение статистики игр
- Тематические наборы слов
- Режим для двух игроков (один загадывает слово)

# 📊 Проект: Текстовый анализатор

## 📝 Описание программы

Текстовый анализатор - это программа для статистической обработки введённого пользователем текста. Программа предоставляет различные метрики и характеристики текста, полезные для его анализа.

### Основные функции:

- **Ввод текста**: пользователь вводит текст непосредственно в программу
- **Анализ данных**: программа вычисляет различные статистические показатели
- **Вывод результатов**: отображение полученной статистики в удобном формате

## 🔍 Анализируемые параметры

### 1. Базовые метрики

- **Количество символов**: общее число знаков в тексте
- **Количество слов**: подсчёт слов (разделённых пробелами)
- **Количество предложений**: определяется по точкам, восклицательным и вопросительным знакам

### 2. Анализ символов

- **Гласные/согласные**: процентное соотношение
- **Цифры и спецсимволы**: их количество и доля в тексте

### 3. Дополнительные метрики
- **Средняя длина слова**: в символах
- **Средняя длина предложения**: в словах
- **Самые частые слова**: ТОП-5 наиболее употребляемых слов

## ⚙️ Технические детали

### Алгоритм работы:
1. Пользователь вводит текст (или несколько абзацев)
2. Программа последовательно вычисляет все метрики
3. Результаты выводятся в консоль


# ♣️ Упрощенный Блэкджек (21)

## 📝 Описание игры

**Цель игры**: Набрать сумму очков, максимально близкую к 21, но не превышающую её.

**Основные правила**:

1. Используется стандартная колода из 52 карт
2. Карты от 2 до 10 дают очки по номиналу
3. Валет, Дама и Король дают 10 очков
4. Туз даёт 11 очков (упрощённый вариант без пересчёта)
5. Игрок и дилер получают по две карты в начале игры
6. Игрок может брать дополнительные карты или остановиться
7. Дилер берёт карты, пока у него меньше 17 очков
8. Побеждает тот, у кого сумма ближе к 21 без перебора

## 💻Описание программы

Программа реализует консольную версию упрощённого Блэкджека. Вот как она работает:

**Начало игры**:

   - Программа создаёт и перемешивает колоду карт
   - Игрок и дилер получают по две карты
   - Показываются карты игрока и одна карта дилера

**Ход игрока**:

   - Программа показывает текущие карты игрока и сумму очков
   - Игроку предлагается выбор: взять ещё карту ("да") или остановиться ("нет")
   - Если игрок берёт карту, она добавляется в его руку
   - Если сумма очков превышает 21, игра сразу завершается поражением

**Ход дилера**:

   - После завершения хода игрока открываются карты дилера
   - Дилер автоматически берёт карты, пока его сумма очков меньше 17
   - Если дилер превышает 21, игрок побеждает

**Определение победителя**:

   - Сравниваются суммы очков игрока и дилера
   - Выводится результат игры (победа, поражение или ничья)
   - Показываются финальные карты и суммы очков обоих участников

Программа использует простой текстовый интерфейс, где все действия выполняются через ввод команд в консоль. Игрок взаимодействует с программой, вводя "да" или "нет" в ответ на предложение взять карту.
