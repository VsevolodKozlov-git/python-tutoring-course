# Урок 17. Как искать расстоянием между цветами?

Как цвет представлен в компьютере?

Любой цвет в реальной жизни можно представить пропорцией:
- R Red
- G Green
- B Blue

В связи с этим в компьютере цвет представлен 3-мя числами от 0 до 255.
Каждое из которых обозначает интенсивность цвета

Нампример:
(255, 0, 0) - ярко-красный
(120, 0, 0) - темно-красный
(0, 255, 0) - ярко-зеленый
(0, 0, 0) - черный
(255, 255, 255) - белый
(255, 255, 0) - ярко-желтый
(120, 120, 0) - темно-желтый

Как понять, какие цвета ближе друг к другу?

Пример задачи.
У нас есть цвет (255, 0, 0) - ярко-красный

А также:
(139, 123, 0)
(210, 0, 0)
(0, 0, 0)
(255, 255, 255)

Как нам понять, какой из них ближе всего к (255, 0, 0)?


А давайте представим цвет в виде точки в 3-х мерном пространстве?

![](dots_20.png)

![](dots_40.png)

Визуально видим, что ближе всего (210, 0, 0)


Но как рассчитать расстояние от одной точки до другой?

Вспомним теорему пифагора

Пусть у нас есть точки (2, 2) и (4, 5)

Какое между ними будет расстояние?

![](pythagor.png)


То есть формула будет такой

$\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$

Или же с нашими координатами

$\sqrt{(4 - 2)^2 + (5 - 2)^2}$


То есть считая:
- $(x_2 - x_1)$ вычисляем длину прямой по оси X
- $(y_2 - y_1)$ по оси y
- $\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$ - теорема Пифагор для треугольника по XY


Но что делать если мы в 3-х мерном пространстве?


Мы просто добавим квадрат разности z под корень.

$\sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$

Например, у нас есть точки (0, 0, 0) и (2, 3, 4)
Тогда расстояние между ними будет:

$\sqrt{(2 - 0)^2 + (3 - 0)^2 + (4 - 0)^2} = \sqrt{4 + 9 + 16} = \sqrt{29}$

Вернемся к нашей задаче с точками в пространстве RGB.
Чтобы понять, какой цвет ближе нам надо просто найти наименьшее расстояние между 2-мя цветами.


Как понять, какого цвета блок?

Если мы приглядимся к блоку, то он состоит из пикселей разных цветов
![](terracota.webp)

И как нам понимать, с каким цветом нам надо искать расстояние?

Для этого нам надо усреднить все пиксели в блоке по каждому из каналов:
- R - красному
- G - зеленому
- B - синему

Но как это сделать в питоне?

Используем PIL и numpy для работы с изображением

PIL - модуль для для чтения изображения
numpy - позволяет работать с изображением, как со списком пикселей

Для начала установим библиотеки при помощи
```
pip install numpy PIL
```

Теперь получим изображение в python:
```python
from PIL import Image
import numpy as np


# Получаем экземпляр класса Image из изображения
img = Image.open('pythagor.png').convert('RGB')
# Преобразуем в массив numpy, чтобы получить значение каждого пикселя
img_list = np.array(img)
# Выводим размерность изображения. 
# Выведится что-то вроде (1000, 1400, 3), где 
# - 1000 - кол-во пикселей в высоту
# - 1400 - кол-во пикселей в ширину
# - 3 кол-во цветовых каналов. В нашем случае RGB
print(img_list.shape)
```

Теперь, когда у нас есть список с пикселями попробуем их получить.
На изображении ниже показано, что координаты пикселей отсчитывают от левого верхнего угла изображения

![](pixel_coord.jpg)




```python
print(img_list[0, 0]) # значение левого верхнего пикселя
print(img_list[0, 1]) # значение пикселя правее предыдущего
```

А как теперь получить значение каждого канала цвета?

```python
print(f'Интенсивность красного верхнего левого пикселя: {img_list[0, 0, 0]}')
print(f'Интенсивность зеленого верхнего левого пикселя: {img_list[0, 0, 1]}')
print(f'Интенсивность синего верхнего левого пикселя: {img_list[0, 0, 2]}')
```

Этого инструментария нам будет достаточно, чтобы посчитать средней цвет в каждом канале цвета для блока целиком.
Напишем функцию для этого:
```python
def get_mean_color(img_list):
    height, width, colors = img_list.shape

    red_sum = 0
    green_sum = 0
    blue_sum = 0

    # Складываем каждый цвет по отдельности
    for h in range(height):
        for w in range(width):
            red_sum += img_list[h, w, 0]
            green_sum += img_list[h, w, 1]
            blue_sum += img_list[h, w, 2]
    
    pixels = width * height # Всего пикселей на изображении

    # Делим на все пиксели изображения и получаем среднее
    red_mean = round(red_sum / pixels)
    green_mean = round(green_sum / pixels)
    blue_mean = round(blue_sum / pixels)

    return [red_mean, green_mean, blue_mean]

print(get_mean_color(img_list))
```

Итог

Теперь для каждого каждого блока мы можем посчитать средний цвет. 
Теперь чтобы понять, какой блок поставить на место пикселя изображения, нам надо будет найти блок с наименьшим расстоянием среднего цвета
