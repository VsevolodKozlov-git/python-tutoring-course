# Урок 18. Змейка


## Требования к игре «Змейка»

### Основной функционал

*   **Расположение игрока относительно поля игры**
    *   Игрок должен автоматически повернуться к полю с игрой в начале выполнения программы
    *   Взгляд игрока должен быть в центре поля
    *   Поле должно быть удалено от игрока так, чтобы он видел его целиком

*   **Движение змейки**
    *   Змейка должна постоянно двигаться в выбранном направлении (вверх, вниз, влево, вправо).
    *   Игрок может изменять направление движения с помощью стрелок на клавиатуре

*   **Появление еды**
    *   На игровом поле в случайном месте должна появляться одна цель (еда), отличная по цвету от змейки.
    *   Когда змейка съедает эту цель, на поле сразу же появляется новая цель в другом случайном месте.

*   **Рост змейки**
    *   Когда голова змейки касается цели, змейка должна становиться длиннее.
    *   Длина увеличивается на один сегмент
    *   Новый сегмент появляется в конце хвоста.

*   **Увеличение скорости**
    *   Каждый раз, когда змейка съедает 3 цели, скорость её движения должна немного увеличиваться.

*   **Завершение игры**
    *   Игра должна немедленно завершаться, если голова змейки сталкивается с краем игрового поля.
    *   Игра также должна завершаться, если голова змейки сталкивается с любой частью её собственного тела (хвостом).
    *   При завершении игры выводится сообщение в чат с текстом «Игра окончена» и итоговым счётом (количество съеденных целей).


### Дополнительные фичи для игры «Змейка»

Реализуйте хотя бы одну фичу. Чем больше, тем лучше.

*   **Выбор сложности в начале**
    *   Игрок может выбрать один из трех уровней сложности: Легкий, Средний, Сложный.
    *   На легком уровне змейка движется медленно, на среднем - быстрее, на сложном - очень быстро.

*   **Еда с ускорением**
    *   Появляется особый тип еды, который при съедании увеличивает длину змейки сразу на 2 сегмента.
    *   После съедания такой еды скорость змейки значительно увеличивается на 10 секунд.
    *   Еда должна быть особого цвета (например, красная) чтобы игрок понимал риск.

*   **Динамические препятствия**
    *   Каждые 5 очков на игровом поле случайным образом генерируются новые препятствия (стены).
    *   Препятствия появляются в свободных местах и остаются до повторной генерации препятствий

*   **Порталы телепортации**
    *   На карте появляются два специальных портала.
    *   При попадании в один портал змейка мгновенно выходит из другого.
