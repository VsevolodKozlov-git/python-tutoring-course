# Техническое задание: Персональное портфолио

## 1. Цель проекта

Создать одностраничный сайт-портфолио, демонстрирующий ваши навыки в области программирования. Сайт должен быть свёрстан с использованием **HTML5** и **CSS3** в соответствии с предоставленными макетами и требованиями. Проект закрепляет знания, полученные в уроках 33–36: семантическая вёрстка, работа с формами, flexbox, позиционирование, переменные CSS и адаптивность.

## 2. Общие требования

- **Семантическая вёрстка** с использованием тегов `header`, `nav`, `main`, `section`, `footer`.
- **Файловая структура**:
    - `index.html` – главная страница (биография).
    - `search.html` – страница «Текстовый поиск».
    - `hangman.html` – страница «Виселица».
    - `blackjack.html` – страница «Black Jack» (заглушка).
    - `css/style.css` – единый файл стилей.
    - `images/` – папка с изображениями (фотография, иконки при необходимости).
- **Цветовая схема** на выбор:
    - Предложенная: [ссылка](https://coolors.co/ccd5ae-e9edc9-fefae0-faedcd-d4a373)
    - Либо любая другая палитра с [coolors.co](https://coolors.co) (обязательно зафиксируйте выбранные цвета в корневых переменных CSS).
- **Кодировка**: UTF-8.

## 3. Функциональные требования

### 3.1. Навигационная панель (общая для всех страниц)

- Панель **всегда закреплена вверху** окна браузера (свойство `position: fixed`).
- Содержит две области:
  1. **Левая часть**:  
     - Текст `Биография Имя` (вместо `Имя` подставьте своё).  
     - Вертикальная черта 
     - Весь текст является ссылкой на главную страницу (`index.html`).
  2. **Правая часть**:  
     - Кликабельные ссылки на страницы:  
       - **Текстовый поиск** (`search.html`)  
       - **Виселица** (`hangman.html`)  
       - **Black Jack** (`blackjack.html`)  
     - Ссылки должны быть разделены пробелами или иным способом (на ваш вкус).

### 3.2. Главная страница (Биография)

#### 3.2.1. Блок с заголовком и фотографией

- Располагается в верхней части страницы **после навигационной панели** (учитывайте отступ, чтобы контент не заезжал под `fixed`-панель).
- Состоит из двух колонок:
  - **Левая колонка** (≈35% ширины блока) – ваша фотография.  
    - Изображение должно иметь атрибут `alt` с описанием.
  - **Правая колонка** – крупный текст `Портфолио Имя`.  
    - Шрифт значительно больше базового (например, `3rem`).

#### 3.2.2. Биографический текст

- Располагается **ниже** блока с фотографией.
- Блок с текстом выровнен по центру страницы, имеет **отступы слева и справа**
- Текст содержит краткую информацию о вас (кто вы, чем занимаетесь, опыт в программировании).  
- **Выравнивание текста** – по левому краю (без `text-align: justify` или `center` для самого текста).

#### 3.2.3. Hard Skills

- Заголовок `Hard Skills`
- Набор «прямоугольников» с закруглёнными углами (свойство `border-radius`), внутри которых указаны конкретные навыки.  
- **Набор навыков**: `python`, `bag of words`, `html`, `css`. Можете добавить свои.
- Прямоугольники должны:
  - Располагаться в **одну строку** и **переноситься на новую строку**, если не хватает ширины экрана.
  - Иметь внутренние отступы, фоновый цвет (из палитры), возможно, границу.
- Весь блок `Hard Skills` выровнен по центру с отступами по бокам, аналогично биографическому тексту.

### 3.3. Страница «Текстовый поиск»

- Заголовок `Текстовый поиск`.
- Форма с настройками поиска, визуально выделенная (например, фоном, рамкой или тенью).  
  Состав формы:
  1. **Выпадающий список** с выбором метода:  
     - `tf-idf`  
     - `bag of words`  
  2. **Текстовое поле**  для ввода поискового запроса.  
  3. Две кнопки, расположенные **в одной строке**:  
     - `Поиск` (тип `submit`)  
     - `Сбросить` (тип `reset`)  

- При клике на «Сбросить» поля формы должны очищаться до начальных значений.  
- **Примечание**: реальная отправка данных не требуется, атрибуты `action` и `method` можно опустить или указать `#`.

### 3.4. Страницы «Виселица» и «Black Jack»

- Каждая страница содержит только заголовок с названием раздела и сообщение:  
  > Раздел находится в разработке


## Нефункциональные требования

### 4.1. Единицы измерения

- **Размеры шрифтов, отступы, ширина/высота элементов** должны задаваться преимущественно в `rem` или `%`.
    

### 4.2. Переменные CSS

- Определите **пользовательские свойства** (CSS-переменные) в селекторе `:root` для:
    - Цветов из выбранной палитры.
    - Базового размера шрифта.   
    - Основных отступов (если требуется). 
- Используйте переменные во всех местах, где применяются соответствующие значения.
    

### 4.3. Адаптивность (желательно, но не строго обязательно)

- Проверьте отображение страницы при разной ширине экрана (от 320px до 1920px).  
- **Минимальное требование**: на узких экранах (менее 640px) элементы не должны выходить за границы, текст должен оставаться читаемым.  
- **Дополнительно (по желанию)**: используйте **медиазапросы** (`@media`) для изменения расположения элементов (например, колонки в блоке с фотографией могут стать вертикальными).
