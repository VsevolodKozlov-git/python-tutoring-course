## 🔎 Фиктивный текстовый поиск

> Он фиктивный, потому что реальный поиск по запросу не происходит. Поиск всегда возвращает одни и те же данные. Реальный поиск мы сделаем позже, когда научимся обращаться к серверу

### Основной функционал:
 
**Ввод поискового запроса**

- На странице присутствует текстовое поле с подписью «Поисковой запрос:»  
- Пользователь может ввести произвольный текст (допускается пустая строка)

Выбор метрики

- TF-IDF
- Bag of words

**Запуск поиска**

- Поиск запускается только после нажатия кнопки «Отправить»  
- При вводе текста без нажатия кнопки никакие действия не выполняются

**Отображение результатов поиска**

- Если поиск был выполнен (кнопка «Отправить» нажата хотя бы один раз), на странице появляется список результатов  
- Каждый элемент списка показывает:
  - Числовую характеристику «расстояние» (чем меньше число, тем ближе результат к запросу)  
  - Название найденного объекта  
- Элементы отображаются в виде вертикального перечня в порядке, заданном системой

**Начальное состояние**

- До первого нажатия кнопки «Отправить» список результатов отсутствует  
- Вместо списка выводится сообщение-подсказка: «Введите запрос, чтобы получить результат»

### Дополнительные функции:
- Если пользователь введет пустую строку, то вывести "ничего не найдено"
- Сортировка результатов по расстоянию или по алфавиту с возможностью выбора принципа сортировки

## 📝 Список задач

### Основной функционал:

**Добавление задачи**

- Пользователь вводит **текст задачи** (обязательное поле)  
- Выбирает **приоритет**: `низкий`, `средний` или `высокий`  
- Указывает **дедлайн** — дату, к которой задача должна быть выполнена  
- Пользователь нажимает кнопку "добавить" и задача сохраняется в общем списке

**Сортировка списка**

На странице присутствует элемент управления, позволяющий выбрать один из трёх режимов сортировки:

- **По порядку добавления** — задачи идут в той последовательности, в которой были созданы (исходный порядок)  
- **По приоритету** — от высокого к низкому (высокий → средний → низкий)  
- **По дедлайну** — от ближайшей даты к самой дальней  

**Удаление задачи**

- Рядом с каждой задачей находится кнопка удаления
- При нажатии задача немедленно убирается из списка и из памяти

**Отметка о выполнении**

- Каждая задача имеет элемент для отметки выполнения (например, чекбокс или кнопка «Выполнено»)  
- При отметке задача визуально меняется: текст зачёркивается, цвет становится менее ярким, но сама запись остаётся в списке  
- Выполненная задача продолжает участвовать в сортировке; повторное нажатие на отметку может снимать её (возвращая задачу в активное состояние)

### Дополнительные функции:

- **Визуальное выделение приоритета** — задачи с разным приоритетом могут отображаться с цветовой индикацией (например, красный — высокий, жёлтый — средний, зелёный — низкий) для быстрого восприятия  
- Фильтрация задач: «все», «активные», «выполненные»  
- Редактирование текста, приоритета или дедлайна у уже созданной задачи  
- Массовое удаление выполненных задач
