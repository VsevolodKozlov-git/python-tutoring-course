#### Оператор if/else/elif
Что выведет этот код?
```python
age = int(input())

if age < 0:
	print('Введен неверный возраст')

if age < 18:
	print('До 18 пиво не продаем')

print(f'Вот ваше пиво')
```


```python
age = int(input())

if age < 0:
	print('Введен неверный возраст')
if age > 0 and age < 18:
	print('До 18 пиво не продаем')
if age > 18:
	print(f'Вот ваше пиво')
```

```python
age = int(input())

if age < 0:
	print('Введен неверный возраст')

	print('До 18 пиво не продаем')

	print(f'Вот ваше пиво')
```

#### Квадратные корни
Напишите программу, которая получает через input целое число.

- Если ввели число, которое после взятия квадратного корня остается целым, то она выводит: `Правильное число` и завершает выполнение.

Совет: для взятия квадратного корня можете использовать функцию `sqrt` из модуля `math`

- Длина больше или равна 8 символов

- Содержит хотя бы одну большую букву

False если хотя бы одна проверка не пройдена

#### Поиск в строке
Напишите функцию `find_in_str`, не используя метод строки `fшnd`. Функция должна принимать 2 аргумента:

1. Строка, в которой необходимо найти подстроку
2. Сама подстрока

Функция должна возвращать индекс начала первого вхождения подстроки в строку. Если подстроки нет в строке, то -1.
Другими словами, она должна работать как  метод find

Советы:

1. Задачу можно решить только используя цикл for или while, но for лучше
2. В цикле вам надо будет перебирать индексы первого вхождения подстроки в строку
3. Для поиска вам придется сравнивать подстроку со срезом основной строки
