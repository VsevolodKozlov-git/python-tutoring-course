Зачем сортировать список?

Алгоритм двоичного поиска:
```python
def binary_search(arr, value):
    # Почему я здесь использую sorted вместо sort?
    arr = sorted(arr)
    start = 0
    end = len(arr) - 1
    while start <= end:
        mid = (start + end) // 2
        if arr[mid] == value:
            return True
        elif arr[mid] < value:
            start = mid + 1
        else:
            end = mid - 1
    return False

print(binary_search([1, 1, 2, 4 ], 3))
```
