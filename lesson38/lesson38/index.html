    Урок 38. Сравнение JavaScript и Python

    Материал урока

    0. Введение

    Как запустить JavaScript

    JavaScript можно выполнить двумя способами: 1. Консоль разработчика – нажми F12, перейди на вкладку «Console», вводи код. 2. HTML-файл с тегом <script> – создай файл .html, подключи скрипт.

    Пример HTML-файла, который выводит сообщение в консоль: 

    <!DOCTYPE html>
<html>
<body>
  <script>
    console.log("Hello from JS!");
  </script>
</body>
</html>

    Привет, мир!

    В Python: 

    print("Hello, world!")

    В JavaScript: 

    console.log("Hello, world!");
    Разница в выполнении: console.log выводит в консоль браузера или среду Node.js, тогда как print в Python пишет в стандартный поток вывода.

    1. Переменные и объявления

    Объявление в Python

    В Python переменная создаётся простым присваиванием: 

    name = "Аня"
age = 15
    Никаких ключевых слов не требуется.

    let и const в JavaScript

    В JavaScript для объявления переменных используются let и const. - let – переменная, которую можно переприсваивать: 

    let name = "Аня";
name = "Борис";   // можно
    Можно объявить без начального значения, тогда переменная получит undefined: 
    let city;
console.log(city); // undefined
    - const – константа, обязательно задаётся сразу и не может быть переприсвоена: 
    const pi = 3.14;
pi = 3.15; // Ошибка! Нельзя менять константу

    Разница в выполнении: В Python имя сразу связывается со значением, переменной «без значения» не бывает (можно присвоить None). В JavaScript движок знает о всех переменных, объявленных через let и const, но использовать их до строки объявления нельзя – они находятся во «временной мёртвой зоне» (Temporal Dead Zone). Попытка обратиться к ним до инициализации вызовет ошибку.

    Упражнения: 1. Объяви let-переменную temperature без начального значения. Выведи в консоль её значение. Подумай, есть ли аналог в Python. 2. Попробуй изменить const-переменную. Какую ошибку ты получишь? Запиши объяснение своими словами.

    2. Типы данных и типизация

    Динамическая типизация

    И Python, и JavaScript – языки с динамической типизацией: Одна и та же переменная может в разные моменты хранить значения разных типов.

    x = 10      # int
x = "привет" # str

    let x = 10;      // number
x = "привет";    // string

    Таблица соответствия типов

    Python JavaScript Примечание
    int, float number JS не разделяет целые и дробные, все – number
    str string
    bool boolean
    None null явное отсутствие значения
    — undefined нет аналога, «значение не задано»
    list array изменяемый, индексация с нуля

    Нестрогое и строгое сравнение в JavaScript

    В Python действует строгое сравнение: значения разных типов никогда не равны. 

    print(1 == "1")   # False

    В JavaScript есть нестрогое равенство == (с приведением типов) и строгое === (без приведения). 

    console.log(1 == "1");   // true  – опасно!
console.log(1 === "1");  // false – правильно
    Рекомендуется всегда использовать === и !==.

    Приведение типов в операциях

    Из-за автоматического приведения JavaScript может дать неожиданный результат при сложении строки и числа: 

    console.log("5" + 2); // "52"
    Python в такой ситуации выдаст ошибку: 
    print("5" + 2)  # TypeError

    Специальные значения: None, null, undefined

    • Python: None – единственное значение для «ничего».
    • JavaScript:
    • null – явное отсутствие значения (программист сам его присвоил).
    • undefined – значение по умолчанию для неинициализированных переменных, несуществующих свойств и т.п.

    Упражнения: 1. Какой результат даст выражение "10" + 5 в JavaScript, а какой – в Python? Проверь в консоли/интерпретаторе. 2. Напиши условие, которое проверяет, равна ли переменная userInput числу 0, используя строгое равенство, чтобы избежать неявного приведения.

    3. Условные конструкции

    Синтаксис if/else

    Python: 

    score = 85
if score >= 90:
    print("Отлично")
elif score >= 70:
    print("Хорошо")
else:
    print("Нужно подтянуть")

    JavaScript: 

    let score = 85;
if (score >= 90) {
    console.log("Отлично");
} else if (score >= 70) {
    console.log("Хорошо");
} else {
    console.log("Нужно подтянуть");
}
    Разница в выполнении: Python определяет блоки отступами, JavaScript – фигурными скобками. Условие в JS обязательно в круглых скобках. Пропуск скобки или отступа меняет логику.

    Логические операторы

    Python JavaScript
    and &&
    or \|\|
    not !

    Пример: 

    if age > 12 and has_passport:
    print("Можно")

    if (age > 12 && hasPassport) {
    console.log("Можно");
}

    Упражнения: 1. Перепиши следующую цепочку с Python на JavaScript: 

    if x < 10:
    print("мало")
elif x < 20:
    print("средне")
else:
    print("много")
    2. Что выведет код, если случайно забыть фигурные скобки? 
    let points = 80;
if (points >= 60)
    console.log("Сдал");
    console.log("Молодец!");
    Проверь себя в консоли.

    4. Циклы

    while

    Синтаксис while почти идентичен.

    Python: 

    n = 3
while n > 0:
    print(n)
    n -= 1

    JavaScript: 

    let n = 3;
while (n > 0) {
    console.log(n);
    n--;
}

    for со счётчиком

    Python использует range: 

    for i in range(5):
    print(i)
    JavaScript – классический цикл с тремя выражениями в скобках: 
    for (let i = 0; i < 5; i++) {
    console.log(i);
}

    Итерация по элементам

    Python: 

    fruits = ["яблоко", "банан"]
for fruit in fruits:
    print(fruit)

    JavaScript предлагает for..of (по значениям): 

    let fruits = ["яблоко", "банан"];
for (let fruit of fruits) {
    console.log(fruit);
}

    Важно: конструкция for..in в JS перебирает индексы/ключи, а не значения

    let fruits = ["яблоко", "банан", "апельсин"];

// for..in – перебирает ИНДЕКСЫ (ключи)
for (let index in fruits) {
    console.log(index);  // 0, 1, 2
}

// for..of – перебирает ЗНАЧЕНИЯ
for (let fruit of fruits) {
    console.log(fruit);  // "яблоко", "банан", "апельсин"
}

    Упражнения: 1. Перепиши цикл for i in range(1, 4): print(i) на JavaScript. 2. Дан массив let colors = ["red", "green", "blue"];. Выведи каждый цвет с помощью for..of.

    5. Функции

    Обычная функция

    Python: 

    def greet():
    return "Привет!"

    JavaScript: 

    function greet() {
    return "Привет!";
}
    Разница в выполнении:
    - Если в Python функция не содержит return, она возвращает None.
    - В JS без return возвращается undefined.

    Лямбда-функции и стрелочные функции

    Python использует lambda для коротких анонимных функций, но тело может состоять только из одного выражения: 

    double = lambda x: x * 2
print(double(5))   # 10

    В JavaScript аналогом служат стрелочные функции (arrow functions), которые могут быть и однострочными, и многострочными: 

    // однострочная – аналогична lambda
const double = (x) => x * 2;
console.log(double(5));  // 10

// многострочная – lambda так не может
const checkAge = (age) => {
    if (age >= 18) {
        return "Можно";
    } else {
        return "Нельзя";
    }
};
    Разница в выполнении: Стрелочная функция может содержать целый блок с операторами, тогда как lambda в Python ограничена одним выражением.

    Упражнения: 1. Напиши функцию isEven(n), возвращающую true/false для чётного числа, в обоих языках. 2. Перепиши стрелочную функцию из двух и более строк в обычную функцию function, а затем придумай, почему такое же поведение нельзя получить с lambda в Python.

    6. Области видимости

    Функциональная vs блочная область видимости

    Python: переменные, объявленные в функции, локальны. Блоки if, for, while не создают отдельной области видимости. 

    def test():
    if True:
        x = 10
    print(x)   # 10 – переменная видна!

test()
    Глобальная переменная может быть маскирована внутри функции, но вне функции блок не изолирует имя.

    JavaScript (с let и const): введена блочная область видимости. Переменная существует только внутри фигурных скобок { }, где была объявлена. 

    function test() {
    if (true) {
        let x = 10;
    }
    console.log(x); // ReferenceError: x is not defined
}
test();
    Разница в выполнении: Этот контраст – одна из главных ловушек при переходе. В JS переменная из блока никогда не «утечёт» наружу, если используется let или const.

    Упражнения: 1. Что выведет следующий Python-код? Почему? 

    for i in range(3):
    message = f"Шаг {i}"
print(message)
    2. Перепиши пример на JavaScript с использованием let, чтобы аналогичное поведение привело к ошибке. Объясни причину.

    7. Заключение: шпаргалка питониста по JavaScript

    Сводная таблица самых частых синтаксических отличий:

    Конструкция Python JavaScript
    Переменная x = 5 let x = 5;
    const X = 5;
    Константа (конвенция) X = 5 const X = 5;
    Вывод print("текст") console.log("текст");
    Условие if x > 0: if (x > 0) { }
    Иначе-если elif else if
    Логические and, or, not &&, \|\|, !
    Цикл со счётчиком for i in range(n): for (let i = 0; i < n; i++) { }
    Итерация по значениям for item in list: for (let item of array) { }
    Функция def func(): function func() { }
    Анонимная функция lambda x: x*2 (x) => x * 2
    Ничего / не задано None null, undefined

    Ключевые моменты, которые нельзя забывать: 1. Всегда используй строгое равенство === в JS. 2. Область видимости в JS блочная (let, const), а в Python блоки не изолируют переменные. 3. Значение по умолчанию для свойства/переменной в JS – undefined. 4. Обычные функции function можно вызывать до их объявления (hoisting), в Python – нет.

    1. Стрелочные функции мощнее lambda, они могут содержать несколько строк. Это основа, позволяющая начать читать и писать простой JavaScript, опираясь на знание Python.
