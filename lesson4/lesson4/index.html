    Новый материал

    Как добавлять в код новый функционал? Импорт модуля math

    Есть 2 синтаксиса импорта модулей:

    • import <module>
    • from <module> import <func1>, <func2>, ...

    Рассмотрим на примере модуля math, который содержит функции и переменные для расширения работы с математикой в python

    Синтаксис import <module>: 

    import math # импортируем при помощи синтаксиса `import <module>`
# Теперь мы можем обращать к содержимому модуля через `math.`
print(3 * math.pi) # число Пи умножили на 3
print(math.factorial(5)) # Вычислили факториал 5-ти

    Синтаксис from <module> import <func1>, <func2>, ...: 

    from math import factorial, pi # импортируем при помощи синтаксиса `import <module>`
# Теперь мы можем обращать к импортированным частям, как к обычным фунцкциям и переменным
# приписка `math.` не нужна
print(3 * pi) # число Пи умножили на 3
print(factorial(5)) # Вычислили факториал 5-ти

    Когда использовать синтаксис import <module>?

    Когда надо использовать много аттрибутов из модуля, в остальных случаях from. Ну а вообще, это ваш выбор.

    Избавляемся от проблем float при помощи Decimal

    Тип Decimal считает числа с плавающей точности без погрешности, но занимают больше места в памяти. Ниже пример с расчетом злосчастного 0.3 

    from decimal import Decimal # из модуля decimal импортируем тип Decimal

a = Decimal('0.1') # Decimal может принимать str, int, float. Однако float не советую, см. ниже
b = Decimal('0.2')
c = Decimal('0.3')

print(a + b - c) # 0.0

    А вот, что будет если вместо строки передать float 

    from decimal import Decimal # из модуля decimal импортируем тип Decimal

a = Decimal(0.1) # Передаем float
b = Decimal('0.2')
c = Decimal('0.3')

print(a + b - c) # 5.5511151231E-18

    Как вы думаете: почему так происходит?

    Decimal можно складывать с целыми числами, но нельзя с float. Складывать с float нельзя, потому что тогда потеряется точность 

    from decimal import Decimal # из модуля decimal импортируем тип Decimal

Decimal("0.1") + 1 # нет ошибки
Decimal("0.1") + 0.1 # ошибка

    Когда стоит использовать Decimal вместо float ?

    Когда вам надо сравнивать 2 числа на равенство

    Когда вам очень важна точность. Например, при расчете денег или научных вычислений

    Но это редкие случаи! Я использую 95% времени float и не жалуюсь
