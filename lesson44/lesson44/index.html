    Практическое задание

    1. Цель работы

    Создать страница, которая позволяет добавлять и удалять продукты с использованием публичного API. На странице присутствуют форма для создания продукта и таблица со списком всех созданных продуктов. Каждый продукт можно удалить отдельной кнопкой.

    С API можно ознакомиться здесь: https://fakeapi.platzi.com/en/rest/products/

    2. Обязательная функциональность

    2.1. Форма добавления продукта

    Форма содержит только те поля, которые пользователь должен заполнить вручную:

    • title – текстовое поле (строка).
    • price– числовое поле (целое или дробное число).
    • description – текстовое поле.

    Поля categoryId и images на форме отсутствуют, так как их значения будут подставляться автоматически (объяснение см. в п. 2.2).

    Под полями расположена кнопка с надписью «Отправить».

    2.2. Создание продукта (POST-запрос)
    • При нажатии на кнопку «Отправить» приложение собирает данные, введённые пользователем (title, price, description).
    • Поскольку API требует обязательные поля categoryId и images, перед отправкой запроса к данным формы автоматически добавляются:
    • categoryId: 1 (соответствует категории «Clothes»);
    • images: ["https://yavuzceliker.github.io/sample-images/image-1021.jpg"] (массив с одним URL-изображением).
    • Таким образом, пользователь их не видит и не заполняет, но итоговый объект, отправляемый на сервер, является полным и соответствует требованиям API.
    • Тело POST-запроса должно быть объектом JSON, содержащим все пять полей: title, price, description, categoryId, images.
    • Отправка выполняется через POST-запрос на эндпоинт /products.
    • Правила обработки ответа:
    • Если HTTP-статус ответа начинается с 2, операция успешна.
      • Из тела ответа извлекается созданный объект продукта (включает уникальный id).
      • Новый продукт добавляется в таблицу (см. п. 2.3).
      • Поля формы очищаются.
    • Если статус не начинается с 2, выводится сообщение об ошибке. Продукт в таблицу не добавляется.
    2.3. Отображение созданных продуктов
    • Под формой находится таблица, изначально пустая.
    • Каждый успешно созданный продукт отображается в отдельной строке таблицы. Минимальный набор отображаемых данных:
    • Название (title)
    • Цена (price)
    • Идентификатор (id), присвоенный сервером
    • В каждой строке таблицы присутствует кнопка «Удалить».
    2.4. Удаление продукта (DELETE-запрос)
    • При нажатии на кнопку «Удалить» у конкретного продукта приложение отправляет DELETE-запрос на эндпоинт /products/{id}, где {id} – идентификатор, полученный при создании этого продукта. Для этого вместо .post используйте .delete
    • Правила обработки ответа:
    • Если HTTP-статус ответа начинается с 2, продукт удаляется из таблицы (строка исчезает).
    • В противном случае выводится сообщение об ошибке, и строка остаётся в таблице.

    3. Технические требования

    3.1. Настройка HTTP-клиента.
    • Создайте экземпляр axios с предварительной конфигурацией через axios.create(): 
      export default const apiClient = axios.create({
  baseURL: 'https://api.escuelajs.co/api/v1/'
});
    • Этот экземпляр разместите в отдельном файле, например api.js.
    • В основном файле приложения (интерфейс и обработчики) импортируйте созданный клиент: 
      import apiClient from './api.js';
    • Все запросы (POST, DELETE) выполняйте только через apiClient.
    3.2. Соответствие API
    • Документация: https://fakeapi.platzi.com/en/rest/products/
    • Разделы «Create a product» и «Delete a product».

    4. Примеры и подсказки

    4.1. Сборка данных перед POST-запросом
    // Данные, введённые пользователем
const userInput = {
  title: 'Мой продукт',
  price: 19.99,
  description: 'Описание товара'
};

// Автоматическое добавление обязательных полей
const productData = {
  ...userInput,
  categoryId: 1,
  images: ['https://yavuzceliker.github.io/sample-images/image-1021.jpg']
};

    5. Критерии проверки

    1. На странице присутствуют форма с полями: title, price, description и кнопка «Отправить».
    2. При отправке к данным формы автоматически добавляются categoryId: 1 и images: ["https://yavuzceliker.github.io/sample-images/image-1021.jpg"].
    3. Выполняется POST-запрос на /products через экземпляр apiClient из файла api.js.
    4. При успешном ответе (статус 2xx) продукт добавляется в таблицу, поля формы очищаются.
    5. При ошибке выводится сообщение, таблица не изменяется.
    6. Таблица отображает созданные продукты (минимум: title, price, id), у каждой строки есть кнопка «Удалить».
    7. DELETE-запрос к /products/{id} отправляется через apiClient.delete(...).
    8. При успехе строка удаляется, при ошибке – выводится сообщение.
